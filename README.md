#Genesis

**Идея решения**
1) openAPI от провайдера
2) перевод в каноническую модель
3) параллельная генерация из модели заготовки интеграции, документации и тестовых примеров

**Реализация**
Много парсеров, на каждый тип (yaml, json, XML)


**Каноническая модель**
Поля:
    info
        title
        description
        version
    sum
    
puts + return для полученного результата
